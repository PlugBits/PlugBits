How it works

  1. It only changes how the view is displayed. It doesn't change kintone settings or records. When you turn it off, the screen returns to normal.
  2. No business data is sent externally. License verification only sends your kintone domain name and license key.
  3. It doesn't touch kintone's internal structure — it runs only on official APIs and events.

How to install

  1. Upload the plug-in's zip file (download the zip) in kintone's plug-in management.
  2. In the target app's settings, add the uploaded plug-in to the app.
  3. Open the plug-in's settings screen, enter your key in the "License" field, and save it (not needed for a second or later app on the same domain. If you haven't purchased it yet, you can start a trial from "Try free for 14 days").

If you've lost your key: enter the email address used at purchase and submit the form, and we'll resend the key to that address.
