AutoSignage

キーボードの無い壁掛けTVでも、画面の隅をタップするだけで一覧の速さとテーマを変えられます。

¥4,980 税込・買い切り・kintoneドメイン単位で1ライセンス

準備中

まずは14日間、無料で試す ― プラグインの設定画面から試用を始められます(下の「入れ方」参照)。

できること

  • 一覧をサイネージ表示に(ヘッダー・メニュー・スクロールバーを非表示)
  • 自動スクロールと自動リロード(間隔・回数を設定可能)
  • 画面右下をタップ、またはマウスを意味のある距離動かすと操作帯が表示(5秒操作がなければ自動で隠れる)。停止/再開・速さ(3段階)・テーマ・全画面を切り替え可能
  • テーマはライト/ダーク/端末の設定に自動追従から選べる
  • 画面がスリープしないようWake Lockをリクエスト(対応ブラウザのみ)

標準機能ではできない理由

標準の一覧には、ヘッダーやメニューを隠して自動スクロール・自動リロードで表示し続けるサイネージ(キオスク)モードがありません。

入れ方

  1. プラグインのzipファイルをkintoneのプラグイン管理にアップロードします
  2. 対象アプリの設定で、追加したプラグインをアプリに追加します
  3. プラグインの設定画面を開き、「ライセンス」欄にキーを入れて保存します(未購入なら「14日間 無料で試す」から試用を開始できます)

SIGNPOSTの対応パターン

  1. 開かれた情報(0-03)に沿って設計。現場の数字を壁掛けTVに出し続け、誰でも見える状態にします。
  2. 利用率の把握を助ける(4-36)に沿って設計。一覧を常時表示する運用を、プラグイン側の操作帯だけで続けられるようにしています。
