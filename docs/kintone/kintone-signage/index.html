AutoSignage ― kintone プラグイン

壁掛け TV の kintone、誰かが毎朝 F5 を押していませんか。

一覧をサイネージ表示にして、自動でスクロールと更新を続けます。キーボードの無い端末でも、画面の右下をタップすれば止める・速さ・テーマ・全画面を変えられます。

こんな場面で

出荷予定の掲示

倉庫のTVに今日の出荷を流しっぱなし。ListKitの「今日」タブと組み合わせる。

工程の進み

工場の各工程の状態を一覧で。更新はkintone側でするだけ。

来客と会議

受付の端末に本日の予定。朝に誰かが触る必要がない。

画面

見せたい行だけが、残る。

左=標準の一覧(ヘッダー・メニュー・スクロールバー)、右=同じ一覧のサイネージ表示。

仕組み

  1. 一覧の表示だけを変えます。kintoneの設定もレコードも変えません。終了すれば元の画面に戻ります。
  2. 業務データは外に送りません。ライセンス確認で送るのはkintoneドメイン名とキーだけ。
  3. kintoneの内部構造に触らず、公式のAPIとイベントだけで動きます。

入れ方

  1. プラグインのzipファイル(zip をダウンロード)をkintoneのプラグイン管理にアップロードします
  2. 対象アプリの設定で、追加したプラグインをアプリに追加します
  3. プラグインの設定画面を開き、「ライセンス」欄にキーを入れて保存します(同じドメインの 2 つ目以降のアプリでは不要です。未購入なら「14日間 無料で試す」から試用を開始できます)

キーを紛失した場合: 購入時のメールアドレスを入れて送信すると、そのアドレスにキーをもう一度お送りします。

設定は 4 か所だけ

サイネージに出すビューを1つ作っておきます(列は少なめが見やすい)。

  1. サイネージに表示するビューを選ぶ
  2. 自動スクロールの速さと、上下での停止時間を決める
  3. 自動リロードの更新間隔を決める
  4. テーマ(ライト・ダーク・自動)を選ぶ
