How it works

  1. Values are written into an ordinary text field. Even if you remove the plug-in, the values that were written stay in place.
  2. Your business data is never sent outside. License verification only sends your kintone domain name and license key.
  3. It works entirely through the official kintone API and events, without touching kintone's internal structure.

How to install

  1. Upload the plug-in zip file (download the zip) to kintone's plug-in management.
  2. In the target app's settings, add the uploaded plug-in to the app.
  3. Open the plug-in's settings screen, enter your key in the "License" field, and save. (This is not needed for the second and later apps on the same domain. If you haven't purchased yet, you can start a trial from "Try free for 14 days.")

If you've lost your key: enter the email address used at purchase and submit, and we'll resend the key to that address.
