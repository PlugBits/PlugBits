文字列条件分岐ビルダー

計算式のIFの入れ子を、画面で組める。

¥1,980 税込・買い切り・kintoneドメイン単位で1ライセンス

文字列条件分岐ビルダーを購入する(¥1,980)

まずは14日間、無料で試す ― プラグインの設定画面から試用を始められます(下の「入れ方」参照)。

できること

  • 条件ルールを上から順に評価し、最初に一致した結果を指定した文字列フィールドへ自動で出力
  • 比較条件は「次と同じ」「次を含む」「この範囲」「次のどれか」など多数の演算子から選べる
  • 比較する値は固定値・他の項目・数式のいずれかを選べる
  • 保存前に「判定テスト」で実際の値を入れ、結果を確認できる

標準機能ではできない理由

標準の計算フィールドでもIFの入れ子で条件分岐を書くことはできますが、数式を組み立てる作業はプログラミングに近く、現場の管理者が自分で作るのは難しいものです。

入れ方

  1. プラグインのzipファイル(zip をダウンロード)をkintoneのプラグイン管理にアップロードします
  2. 対象アプリの設定で、追加したプラグインをアプリに追加します
  3. プラグインの設定画面を開き、「ライセンス」欄にキーを入れて保存します(未購入なら「14日間 無料で試す」から試用を開始できます)

SIGNPOSTの対応パターン

  1. 現場主体の業務改善(0-01)に沿って設計。IFの入れ子を画面操作で組めるようにし、管理者自身で設定できる形にしています。
  2. 標準機能を置き換えない(3-29 基本機能で対応→難しければプラグインの順)に沿って設計。標準の計算フィールドでできる範囲を壊さず、組み立てづらい部分だけを補います。
