仕組み

  1. 値はふつうの文字列フィールドに入ります。プラグインを外しても、入った値はそのまま残ります。
  2. 業務データは外に送りません。ライセンス確認で送るのはkintoneドメイン名とキーだけ。
  3. kintoneの内部構造に触らず、公式のAPIとイベントだけで動きます。

入れ方

  1. プラグインのzipファイル(zip をダウンロード)をkintoneのプラグイン管理にアップロードします
  2. 対象アプリの設定で、追加したプラグインをアプリに追加します
  3. プラグインの設定画面を開き、「ライセンス」欄にキーを入れて保存します(未購入なら「14日間 無料で試す」から試用を開始できます)

設定は 3 か所だけ

出力先に文字列(1行)フィールドを1つ置いておきます。

  1. 出力先の文字列フィールドを選ぶ
  2. ルール(条件と出す値)を上から並べる
  3. 判定テストで実際の値を試す

詳しい手順は マニュアル へ。
