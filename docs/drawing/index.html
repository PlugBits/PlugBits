BASIS — 台帳が古くならない理由

kintoneに貯まってきたものが、そのまま資産になる

受注 → 製造指示 → 検査

図面管理システムは、登録という仕事が増えた分だけ、台帳が古くなっていきます。

kintoneでは、日々の流れの中で図面が添付され、副産物として検索対象が貯まります。

いま使っているkintoneアプリに後付けします。図面を移す必要はありません。

いまのアプリに後付け 図面の移行なし データはkintoneの中
