SUBJECT — 検索で出ない情報

検索窓に入れる言葉が、ない

品番や品名が分かっている図面は、いまのkintoneでも探せます。困るのはその先です。

刃物が入らなかった。薄板が反った。この掴み方だと変形した。現場で効くのは、こうした情報です。そしてこれらは品番と結びついていません。

手がかりは「前に似た形をやった」という記憶だけです。形が似た過去の図面にたどり着いて、はじめてその先の情報が出てきます。

この製品が受け持つのは、その「形で辿る」部分です。

PROCEDURE — 検索から先の流れ

図面にたどり着いてからが、本題です

  1. STEP

    図面から探す

    詳細画面のボタンひとつで検索します。手元のPDFをドラッグして探すこともできます。

  2. →

  3. STEP

    形の似た順に並ぶ

    図番も品名も入力しません。似ている順に候補が並びます。

  4. →

  5. STEP

    レコードへ進む

    図面はkintoneのレコードに付いています。工程、加工条件、不具合履歴、部品構成へ、そのまま進めます。

BASIS — 台帳が古くならない理由

誰も台帳を作らないのに、資産が貯まる

図面管理システムを導入すると、「図面を登録する」という新しい仕事が生まれます。多くの場合、初期投入が終わると更新が止まり、台帳は古くなっていきます。

kintoneでは、受注、製造指示、検査という日々の流れの中でレコードが立ち、図面が添付されていきます。台帳を作ろうとした人は誰もいないのに、業務の副産物として検索対象が増えていきます。

このプラグインは、いま使っているkintoneアプリに後付けします。図面をどこかへ移す必要はありません。データはkintoneに残ります。

自社で用意した約5,000点の図面で検証したところ、探していた図面が1位に表示された割合が82.6%、上位10件までに含まれた割合が95.7%でした。図面の内容や点数によって結果は変わります。
