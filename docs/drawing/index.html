SECURITY — 図面の扱い

図面は、貴社の機密として扱います

図面PDFそのものは、お客様のkintoneに置いたままです。お預かりするのは検索用の数値データと、AES-256で暗号化したサムネイルだけ。復号鍵は当方のサーバーに保存されません。

データはお客様ごとに完全に分離され、AIの学習には一切使いません。解約時は、お預かりしたデータをすべて削除します。

FAQ — よくある質問

よくある質問

どんなファイルに対応していますか?

PDFとTIF(1ページ目)が対象です。CADデータ(DWG等)は、PDFに出力してご利用ください。

スキャンした紙図面でも探せますか?

探せます。検証に使った実図面の多くはスキャン図面で、傾きやかすれがあっても形で検索できることを確認しています。

無料プランと有料プランの違いは?

登録できる枚数と、AI補正の有無です。同じ図面での実測では、検索精度(上位5件以内)が無料プラン構成で94.1%、AI補正ありで100%でした。

導入に打ち合わせは必要ですか?

不要です。登録からプラグイン設定・図面の一括登録まで、すべてオンラインで完結します。設定はkintoneの管理画面から10分ほどです。

解約するとデータはどうなりますか?

お預かりした検索用データ・サムネイルをすべて削除します。図面PDFはお客様のkintoneにあるため、失われるものはありません。

kintoneのコースに条件はありますか?

プラグインが利用できるスタンダードコース以上が必要です。
