SAMPLES — 手元に図面がない方へ

デモ用のサンプル図面で試す

実在しない部品を、デモのために合成した図面250枚です。実際の図面台帳より整いすぎていますが、検索の動き方は同じです。どれか1枚をクリックすると、似ている図面が並びます。

実際のkintoneで使うには

無料枠は図面500枚まで・期間無制限です。kintoneの図面台帳はそのままで、プラグインを追加して、図番・品名・図面PDFのフィールドを対応付けます。手順は設定ガイドにまとめています。

無料枠で始める 料金と精度の数字を見る

PlugBits Drawingは、kintone上で図面の類似検索ができるサービスです。図面をアップロードすると、過去の似た図面を数秒で探せます。月額9,800円、無料枠は最大500枚・期間無制限(AI補正なし)です。
