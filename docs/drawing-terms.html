PlugBits Drawing 利用規約

本規約は、PlugBits（プラグビッツ。以下「当方」といいます。）が提供する類似図面検索サービス「PlugBits Drawing」（以下「本サービス」といいます。）の利用条件を定めるものです。本サイトおよび当方が提供するプラグイン全般については別途利用規約が適用され、本規約は本サービスに関して優先して適用されます。

第1条（適用）

本規約は、本サービスの利用に関する当方と契約者との間の一切の関係に適用されます。契約者が申込みを行った時点で、本規約に同意したものとみなします。

第2条（サービス内容）

  1. 本サービスは、kintone 上の図面ファイルを対象とした類似画像検索機能を、kintone プラグインおよび API として提供するものです。
  2. 本サービスの利用には、契約者自身が契約する kintone（スタンダードコース以上）が必要です。kintone 自体の障害・仕様変更に起因する不具合について、当方は責任を負いません。

第3条（アカウントとAPIキー）

  1. APIキー等の認証情報は契約者の責任で管理し、第三者に開示してはなりません。
  2. 認証情報の漏えいにより生じた損害について、当方は責任を負いません。漏えいの疑いがある場合は速やかに当方に通知するものとし、当方はキーの再発行を行います。

第4条（料金および支払）

  1. 料金は料金ページに定めるとおりとします。
  2. 月額プランは申込日を起算日として毎月、年額プランは毎年、自動更新されます。
  3. 初回申込みから30日以内に解約を申し出た場合、受領済み料金を全額返金します（30日返金保証）。それ以外の解約における日割り・月割りの返金は行いません。
  4. 無料プランは予告のうえ内容を変更することがあります。

第5条（契約者データの取扱い）

  1. 契約者が本サービスに登録した図面その他のデータ（以下「契約者データ」といいます。）の権利は契約者に帰属します。
  2. 当方は、契約者データを本サービスの提供・保守・障害対応の目的にのみ取り扱い、機械学習モデルの学習に使用しません。
  3. 解約後、当方は契約者データ（検索インデックス・サムネイルを含む）を30日以内に削除します。
  4. 詳細は別途定めるセキュリティポリシーによります。

第6条（禁止事項）

契約者は、次の行為をしてはなりません。

  1. 法令または公序良俗に違反する行為
  2. 本サービスの逆コンパイル・リバースエンジニアリング
  3. 第三者へのアカウント貸与・再販売（当方が書面で認めた場合を除く）
  4. 本サービスの運営を妨害する行為、または過度の負荷を与える行為
  5. 権利を有しない図面データの登録

第7条（精度の非保証）

  1. 本サービスの検索結果は、AIによる類似度の推定に基づくものであり、すべての類似図面の検出、および検索結果の正確性・完全性を保証するものではありません。
  2. 検索結果を利用した設計・見積り・製造その他の業務上の判断は、契約者自身の責任と確認のもとで行うものとします。

第8条（サービスの変更・中断・終了）

  1. 当方は、契約者への事前通知のうえ、本サービスの内容を変更または終了できます。有料契約期間中にサービスを終了する場合、残期間分の料金を日割りで返金します。
  2. 保守・障害・不可抗力により、事前通知なくサービスを一時中断することがあります。

第9条（免責・責任制限）

  1. 当方は、本サービスの利用に関連して契約者に生じた損害について、当方に故意または重過失がある場合を除き、直近12ヶ月間に契約者が当方に支払った金額を上限として賠償責任を負い、逸失利益・間接損害については責任を負いません。
  2. 無料プランの利用については、当方は一切の賠償責任を負いません。

第10条（規約の変更）

当方は、契約者の一般の利益に適合する場合、または合理的な必要がある場合、本規約を変更できます。変更後の規約は、本サイトへの掲載および契約者への通知から14日後に効力を生じます。

第11条（準拠法・管轄）

本規約は日本法に準拠し、本サービスに関する紛争は東京地方裁判所を第一審の専属的合意管轄裁判所とします。
