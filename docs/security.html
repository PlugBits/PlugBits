セキュリティポリシー

お客様の図面は、設計ノウハウそのものです。PlugBits Drawing がどのように図面データを保護しているかを説明します。

データの流れ

図面PDFはお客様の kintone に保存されたままです。本サービスがお預かりするのは、検索のために生成した以下のデータのみです。

保存するもの形式
検索用の特徴ベクトル 図面を数値列に変換したもの（画像への復元はできません）
検索結果表示用サムネイル AES-256-GCM で暗号化して保存します。復号鍵はお客様の kintone 内にのみ存在し、当方のサーバーには保存されません。
図面のメタデータ 図番・品名など、検索精度の向上に使う項目

保護の仕組み

  • 通信の暗号化: すべての通信は TLS で暗号化されます。
  • テナント分離: お客様ごとに独立した名前空間でデータを管理し、認証キーなしには自社のデータにもアクセスできません。他社のデータに触れる経路は存在しません。
  • AIの学習に使用しません: 図面の解析に使用する AI（Google Cloud）は、入力データをモデルの学習に使用しない契約条件で利用しています（Vertex AI のデータガバナンス、Google Cloud サービス固有規約）。当方自身もお客様のデータを学習に使用しません。
  • 保存場所: サーバーは Google Cloud（東京リージョン）、検索インデックスは Qdrant Cloud で管理しています。

解約時のデータ削除

解約後30日以内に、特徴ベクトル・暗号化サムネイル・メタデータのすべてを削除します。お客様の kintone 内の図面はそのまま残ります（当方は元データを保持していないため、「返却」の必要がそもそもありません）。

脆弱性の報告

セキュリティ上の問題を発見された場合は support@plugbits.app までご連絡ください。
