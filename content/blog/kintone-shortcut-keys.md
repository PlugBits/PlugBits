kintoneには、マウスを使わずに操作できるショートカットキーが標準で用意されています。特別な設定は不要で、使える画面は「レコード一覧」「詳細・編集・追加」「通知」です(画面右上の「？」アイコンから、その画面の一覧を確認できます)。この記事では画面別の一覧と、標準には無い動きを説明します。

## レコード一覧画面でキーボードだけで動く

一覧画面では、次のキーで操作できます。

| キー | 動作 |
|---|---|
| j / k | 次/前のレコードを選択 |
| Enter / o | 詳細を表示 |
| e / c | 編集/追加 |
| n / p | 次/前のページ |
| / | 検索欄にフォーカス |
| ? | 一覧を表示 |

レコードを1件ずつ確認する作業なら、この6種類だけでマウスに持ち替えずに進められます。検査記録を連続で開く作業では、jとkの移動だけで十分です。標準機能なので、追加のツールは要りません。

## 詳細・編集・追加画面でも一覧と地続きに動く

詳細・編集・追加(再利用)画面では、次のキーが使えます。

| キー | 動作 |
|---|---|
| j / k | 次/前のレコードを選択 |
| Ctrl+s | 変更を保存 |
| Esc | 編集を取り消し |
| g → a / g → i | 一覧/絞り込み結果へ戻る |
| / ・ ? | 検索/一覧表示 |

一覧→詳細→編集→保存という流れが、キーだけでつながります。入力作業が多い人ほど、Ctrl+sの保存だけでも覚える価値があります。

## 通知画面も同じ考え方で動く

通知画面にも、次のキーがあります。

| キー | 動作 |
|---|---|
| j / k | 次/前の通知を選択 |
| Enter | 通知を開く |
| x | 既読/未読を切り替え |
| g → a/m/u | フィルタを切り替え |

通知をまとめて処理する日は、j・k・xだけで流し読みできます。普段から通知を開かない人には不要です。

## 覚えても届かない場所がある

ここまでのキーは、画面の中の操作を速くするものです。画面そのものを切り替える動き、とくに設定画面(プラグイン、JavaScript/CSS、アクセス権、通知条件)への移動は、標準には用意されていません。公式の一覧にも出てきません。

自分でkintoneを作り続けていると、ここが重みを感じる部分です。アプリが増えるほど「歯車→設定タブ→対象の設定」をたどる回数が増えます。この移動が解決せず、ツールを作った経緯は以前noteに書きました(https://note.com/plugbits/n/nc648a8a99f2e)。

一覧やレコードの操作だけなら、標準のキーで十分です。設定変更を繰り返さない人には不要です。ただ、すべて覚えても設定画面への移動は範囲外です。

標準に無い「設定画面への移動」だけを補う無料のChrome拡張があります。PlugBits Launcherは、Ctrl+/でパレットを開き「plugin」「js」のように打つと、設定画面へ直接移動できます。
