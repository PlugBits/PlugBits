kintoneの一覧で列の幅を広げても次に開くと戻っている、自分の画面と同僚の画面で幅が違う、という状況は「保存されていない」のではありません。標準の列幅は既定でログインユーザーとWebブラウザーの組み合わせに保存される仕組みで、端末やブラウザが変わると外れます。全員に同じ幅を固定したい場合は、アプリ管理権限を持つ人が別の操作でアプリの設定として保存できますが、そのあとで個人が自分で列幅を変えると、そちらが優先されて表示が揺れます。

## 既定の列幅は、ログインユーザーとブラウザの組み合わせに閉じて保存される

一覧画面でフィールドの境界線をドラッグして列幅を変える操作自体は、標準のままでも保存されます。公式ヘルプには、変更した列幅はログインユーザーとWebブラウザーの組み合わせで保持され、組み合わせが変わると表示されないと明記されています。保存先は本人専用・ブラウザ単位です。同じ人でも会社のPCとノートPCで幅が違って見えたり、チームの数人が同じ一覧を見ているのに列幅がバラバラだと感じたりするのは、多くの場合、各自が別々に調整した結果がそのまま個別に残っているだけで、設定が壊れているわけではありません。

1人が1台のPCだけで使う運用なら、この狭さは問題になりません。複数端末を使う人や画面を揃えたいチームでは、個人保存だけでは足りないと先に理解しておくと余計な調整をせずに済みます。

## 全員で揃えるにはアプリ設定への保存が要り、個人の変更があとから上書きする

全員に同じ列幅を見せたい場合は、アプリ管理権限を持つ人が一覧画面のメニューから現在の列幅をアプリ設定に保存する操作を選ぶ必要があります。公式ヘルプには、この操作で調整済みの一覧はほかのユーザーも同じように利用できるとあります。ただし共通設定は絶対ではなく、同じヘルプにはユーザーごとの列幅設定が優先されるとも書かれています。各メンバーが自分で幅を変えた記録がすでにある場合は、共通設定よりそちらが優先され、管理者が揃えたはずの幅が一部の人だけ違って見える原因になります。

まだ列幅を触っていない人にはアプリ設定の幅がそのまま効くので、多くの場面はこの操作だけで足ります。すでに各自が幅を変えている人まで揃えたいなら、個人側が優先される前提を踏まえて本人に声をかけます。

## 自分のアプリが今どちらの状態かを確かめる手順

自分のアプリが今どちらの状態かは、次の手順で確かめられます。一覧画面右上のアプリ設定メニューに現在の列幅をアプリ設定に保存する項目が出ていれば、自分にアプリ管理権限があると分かります。出ない場合は閲覧側の権限しかありません。次に、同じ一覧を別のブラウザで開き幅が違うかを見ます。違えば自分だけの個別設定が乗っている状態、同じなら共通設定か初期値のままです。チームで揃えたいときは、この2つを関係者それぞれに確認してもらうと声をかける相手を絞れます。

列幅のパターンを自分用に保存して切り替えたい場合は、無料の Chrome 拡張 PlugBits Launcher の Grid Edit で、列のレイアウトをプリセットとして残す方法もあります。
