The number of records kintone shows at once in a list view can be changed by each user from the options icon in the upper right corner of the screen, under the "Number of Records" menu. The official kintone help documentation states that the default is 20 records and that users can pick a different number from that menu. However, the list of selectable numbers and the maximum value are not spelled out in the help page text as of October 2026. To get a definite answer on whether you can display more than 100 records, you need to open the menu in your own app and check.

## You can change the record count from the list view options menu

Changing how many records appear in a list view is a standard feature, not something that requires customization. According to the official kintone help documentation, you open the list view you want, click the options icon in the upper right corner, and choose a number from the "Number of Records" menu. The default setting is 20 records.

If you leave this at 20, apps with a lot of records end up with more pagination or scrolling. Raising the displayed count reduces how often you need to click to the next page for the same list. If you just want to see a few dozen more records at a time, opening this menu is all it takes.

On the other hand, the help page text does not spell out how high the number can go or what the maximum is (as of October 2026). If you're trying to confirm this just by reading documentation, you won't find the answer there — you'll need to open the menu in your app and look at the actual options.

## The record count is a per-user setting; admins can't apply it for everyone at once

Changing the displayed record count is a personal setting tied to each user, not an app-wide setting. The official kintone help documentation states that the chosen record count carries over across apps and browsers for that user, but it also makes clear that this is not something an app administrator or system administrator can set in bulk for all users.

In other words, if one person changes their record count to 100, it has no effect on what other members see when they open the same app. If a team looking at the same list sees different numbers of records per page, that isn't a bug — it simply reflects each person's own individual setting.

For an app used by just one person, this isn't much of an issue: set it once and it sticks. If you want everyone on a team to see the same record count, the official help documentation doesn't describe any way to do that other than having each member make the same change individually (as of October 2026).

## How to check which numbers are available and what the limit is in your app

Since the help documentation doesn't list the available numbers, the most reliable way to find out is to check directly in your own app. Open the record list for the app in question, click the options icon in the upper right corner of the screen, and select "Number of Records." Write down the numbers listed there and check whether the highest one meets the count you're looking for.

Even if it doesn't reach the number you want, the help documentation text doesn't reveal a maximum, so the options shown in that menu are effectively your answer. If the app is shared by a team, it's worth having other members check the same menu too — that way everyone understands both the available options and the fact that this is a per-user setting.
