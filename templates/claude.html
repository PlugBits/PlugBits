Claude Code、
最初の 1 行から

Claude Code に日本語で頼むだけで、コードを書かずに道具を作っている会社の記録です。中古の Windows 1 台で毎日使っています。

ショートを見る 無料ガイドを受け取る

Windows に入れる

おすすめはアプリ。Node も CLI も要りません。有料プラン(Pro 以上)が必要です。

  1. 1claude.com/download から入れる

  2. 2サインインする

  3. 3左の「Code」タブを開く

黒い画面で使いたい人

PowerShell に貼る:

irm https://claude.ai/install.ps1 | iex

CMD の人:

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

管理者権限は不要。入れた直後に「claude が見つからない」と出たら、新しい窓を開いてください。
