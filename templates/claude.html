Windows に入れる

おすすめはアプリ。claude.com/download からインストーラを入れる → サインイン → 左の「Code」タブ。Node も CLI も要りません。有料プラン(Pro 以上)が必要です。(出どころ: 公式 Desktop quickstart)

黒い画面で使いたい人は 1 行。PowerShell に貼る:

irm https://claude.ai/install.ps1 | iex

CMD の人:

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

管理者権限は不要。入れた直後に「claude が見つからない」と出たら、新しい窓を開いてください。(出どころ: 公式 Set up Claude Code)

無料ガイド「Claude Code はじめの 1 週間」

1 日 1 つ、7 日で自分の仕事を 1 つ日本語で頼めるところまで。デスクトップアプリだけ。登録した人に届けます(仕上げ中)。

週に 1 通、月曜の朝に『作って売るまでの道中記』も届きます。いつでも解除できます。

PlugBits は、kintone の小さな不便を減らす道具を作っています。アプリ間の移動を速くする Chrome 拡張 Launcher は無料。プラグインは買い切りで、14 日間無料で試せます。kintone のプラグインを Claude Code で作る mod も GitHub で公開しています(PlugBits/relay)。
